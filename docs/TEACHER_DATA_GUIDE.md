# Teacher Data Guide

The spreadsheet separates three different dimensions so that participation or technology problems are not mistaken for low language ability.

## 1. Result

Read:

- Accuracy
- First-try accuracy
- Correct responses
- Best streak
- Word-level performance

**Accuracy** shows performance across scored attempts.

**First try** is more useful for retrieval strength because it shows what the learner could produce before correction or repetition.

## 2. Participation

Read:

- Sessions
- Practice minutes
- Activities started/completed
- Distinct words practiced
- Evidence volume

Low participation is not the same thing as low ability.

## 3. Process

Read:

- Retry load
- Bee Arena rounds
- Overtime markers
- Technical microphone events

Technical microphone errors are stored separately and must not reduce the learner's academic interpretation.

## Student_Overview

This is the fastest teacher-control view. Each learner has one row with:

- sessions;
- practice minutes;
- evidence count;
- accuracy;
- first try;
- completion;
- Bee Arena rounds;
- mic errors;
- distinct words;
- evidence strength;
- flag;
- recommended teacher action.

## Dashboard

Use the student selector.

Pedagogical flags:

- **COLLECT DATA**: fewer than 5 scored responses. Gather more evidence before deciding.
- **PRIORITY**: accuracy below about 60%. Use model -> guided practice -> independent retrieval.
- **DEVELOPING**: accuracy is improving but not stable. Use short spaced-retrieval cycles with immediate feedback.
- **RETRIEVAL**: overall accuracy is acceptable but first-try recall is weak. Reduce cues and add delayed retrieval.
- **SECURE**: maintain with spaced review and transfer to Bee Arena.

## Word_Analysis

Use this to decide *what words* to reteach.

A word can be:

- **Not practiced**
- **Low evidence**
- **HIGH**
- **MEDIUM**
- **MAINTAIN**

For a HIGH-priority word, use:

1. sound/model;
2. segment;
3. spell;
4. say;
5. retrieve again later in the same lesson.

## Bee Arena

Bee Arena is a **competition-protocol rehearsal**:

SAY -> SPELL -> SAY AGAIN.

The timer is a fluency reference. It is not eliminatory in practice mode.

Only add pressure once accuracy is stable.
